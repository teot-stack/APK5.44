# Compilar Río Pinto Coach Android v5.4.400 en GitHub

1. Reemplazá el contenido del repositorio por el contenido de este proyecto.
2. Conservá `.github/workflows/build-apk.yml` en la raíz del repositorio.
3. Hacé commit sobre `main` o `master`.
4. Entrá en **Actions → Build Android APK**.
5. Seleccioná **Run workflow**.
6. Al finalizar, descargá **RioPintoCoach-v5.4.400-debug-apk**.
7. Dentro encontrarás `RioPintoCoach-v5.4.400-debug.apk`.

Esta versión incorpora servicios nativos para segundo plano; ya no es sólo una envoltura WebView.
