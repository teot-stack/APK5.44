# Río Pinto Coach Android v5.4.400

Primera versión híbrida con núcleo Android nativo persistente.

## Incluye
- WebView con la interfaz aprobada.
- Foreground Service para entrenamiento.
- Cronómetro y cambios automáticos de fase nativos.
- GPS nativo con pantalla bloqueada.
- TTS Android nativo para descripción de etapas.
- Selector de carpeta musical mediante Storage Access Framework.
- Permiso persistente sobre memoria interna o SD.
- MediaPlayer nativo con reproducción continua y cambio automático de pista.
- Notificación permanente con Pausa/Continuar.
- Persistencia y restauración de sesión.

## Compilar
Actions → Build Android APK → Run workflow.

Artefacto esperado: `RioPintoCoach-v5.4.400-debug-apk`.
