# Río Pinto Coach v4.2.001

PWA Android-first para ejecutar y personalizar el plan Camino al Desafío Río Pinto 2027.

## Publicación
Publica todo el contenido del ZIP en GitHub Pages o cualquier servidor HTTPS. El GPS no funciona desde `file://` y requiere autorización del usuario.

## Funciones principales
- Plan semanal del manual y editor de períodos.
- GPS para distancia, velocidad y desnivel.
- Voz, avisos de cambio y metrónomo de cadencia.
- Funcionamiento offline después de la primera carga.

## Prueba recomendada
1. Publicar bajo HTTPS.
2. Abrir Configuración y activar GPS y sonidos.
3. Preparar un entrenamiento, editar una fase y comenzar.
4. Autorizar ubicación.
5. Verificar transición hablada, metrónomo y avisos finales.
